# PyPassVault
a password manager created with python

## Why this project?
- Stores users' passwords for various apps and websiteswith a strong focus on security
- Generates strong passwords
- Features a user-friendly design and an intuitive interface

## What data is stored?
- Password
- Name of the site or app
- Link
- Specific tags for search purposes

## What can the user do?
- Create an account
- Log in to their account
- Save a password
- View saved passwords
- Search for passwords
- Edit a password
- Delete a password
- Generate a random password
- Create a secure note
- Edit a note
- Delete a note
- Log out of the account
